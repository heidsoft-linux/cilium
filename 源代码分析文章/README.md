## 实践建议

### 1. 环境搭建
```bash
# 搭建Cilium开发环境
git clone https://github.com/cilium/cilium.git
cd cilium
make dev-doctor  # 检查开发环境依赖
```

### 2. 代码编译
```bash
# 编译BPF程序
cd bpf
make bpf_all

# 查看编译选项
make help
```

### 3. 调试和测试
```bash
# 运行测试
make -C bpf tests

# 查看BPF程序状态
cilium bpf lb list
cilium bpf policy get
```

### 4. 性能分析
```bash
# 性能监控
cilium monitor
cilium metrics list

# 性能测试
make -C bpf build_all BUILD_PERMUTATIONS=1
```
